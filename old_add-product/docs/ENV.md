# Переменные окружения (.env)

## Главный источник

**Единственный рекомендуемый файл конфигурации — `/.env` в корне проекта** (рядом с `frontend/` и `backend/`).

- Сайт и API загружают только его: `Config::loadEnv()` без аргументов читает `dirname(__DIR__, 2) . '/.env'` (см. `backend/src/Config.php`).
- Точки входа: `backend/api/index.php`, `frontend/index.php`, а также любой код, вызывающий `Config::get()` или `Config::loadEnv()` (в т.ч. `backend/src/Db.php`, `backend/src/Auth.php`).

## Шаблон (пример)

- **Версионируется только шаблон:** `env/.env.example`.
- Скопируйте его в корень как `.env` и подставьте реальные значения:

  ```bash
  cp env/.env.example .env
  ```

  Windows (cmd): `copy env\.env.example .env`

- Файл `.env` в корне и файл `env/.env` в репозитории не коммитятся (указаны в `.gitignore`).

## Порядок поиска при запуске миграций

Скрипт `backend/bin/migrate.php` ищет конфигурацию в таком порядке:

1. `/.env` (корень проекта)
2. При отсутствии — `env/.env` (legacy fallback)

Если ни один файл не найден, скрипт завершается с ошибкой. Для сайта и API используется только корневой `/.env` (мигратор может работать и с `env/.env`, если в корне нет `.env`).

## Обязательные переменные

| Переменная | Назначение |
|------------|------------|
| `POSTGRES_HOST`, `POSTGRES_PORT`, `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | Подключение к PostgreSQL |
| `APP_BASE_URL` | Базовый URL приложения (без завершающего слэша) |
| `APP_LOCALE_DEFAULT` | Локаль по умолчанию: `ru` или `en` |

Остальные (SMTP, OpenAI, DeepSeek, Qdrant, Proxy, eMall API и т.д.) зависят от используемых функций; см. комментарии в `env/.env.example` и `docs/env/README.md`.

## Про дубликаты

- **Корневой `env.example`:** если в корне лежит файл `env.example`, не используйте его как источник истины — это дубликат шаблона. Рекомендуется удалить или не коммитить; единственный версионируемый шаблон — `env/.env.example`.
- **`env/.env`:** используется только как запасной вариант мигратором; для единообразия лучше держать один файл — `/.env` в корне.
